Boring Notch — AI Live Activities（私人版 / personal build）

安裝 Install
1. 先結束正在執行的 Boring Notch（如果有的話）。
   Quit Boring Notch if it is already running.
2. 把 Boring Notch.app 拖進 Applications。
   Drag Boring Notch.app onto Applications.
3. 從「應用程式」打開 Boring Notch，然後退出這個磁碟映像。
   Open it from Applications, then eject this disk image.

連接 Claude Code / Codex
4. 設定 → AI Activities → 在 Claude Code 或 Codex 旁按 Connect。
   Settings → AI Activities → Connect beside Claude Code or Codex.
5. 連接後開一個「新的」session。Codex 另外要在 /hooks 裡信任新的 hooks。
   Start a NEW session after connecting. Codex also needs you to trust the hooks in /hooks.
   一定要在裝進 Applications 之後再按 Connect，hooks 才會指向正確的位置。

燈號 Lights
紅 Red：工作中 working
黃 Yellow：在等你回覆或核准 needs your answer or approval
綠 Green：這一輪回應結束 this response finished

這個版本不會自動更新。有新版時直接用新的 DMG 覆蓋即可。
This build does not auto-update; install a newer DMG over it.
