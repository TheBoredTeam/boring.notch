## Variant: Soft neutral capsule

### Design stance
Retain clear button affordance while removing the saturated fill and glow that compete with the reminders.

### Key choices
- Layout: Compact capsule in the existing header position.
- Typography: Small semibold rounded-system label.
- Color: Translucent neutral surface; accent appears mainly inside the trailing mark.
- Interaction: Surface lifts subtly and the trailing mark fills on hover; click produces a tinted confirmation state.

### Trade-offs
- Strong at: Familiarity, discoverability, and visual balance.
- Weak at: Still reads as a conventional pill button.

### Best for
- A safe, app-consistent replacement that remains obviously clickable.
