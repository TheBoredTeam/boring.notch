## Variant: Trailing action orb

### Design stance
Separate the explanatory label from a compact, tactile action control so the header stays open and modern.

### Key choices
- Layout: Plain label followed by a standalone circular action.
- Typography: Muted label that brightens on hover.
- Color: Neutral at rest; accent fills only the circle during interaction.
- Interaction: Orb fills, rotates, and scales on hover; click turns it into a green completion mark.

### Trade-offs
- Strong at: Personality and a clear focal interaction without a large filled shape.
- Weak at: Slightly more animated and expressive than the rest of the app.

### Best for
- A distinctive but compact action that still feels at home in the notch.
