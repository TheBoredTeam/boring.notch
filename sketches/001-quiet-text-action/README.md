## Variant: Quiet text action

### Design stance
Keep the workflow content dominant and make finishing feel like a lightweight navigation action.

### Key choices
- Layout: Unboxed text and arrow in the header.
- Typography: Small semibold rounded-system label.
- Color: Neutral text with accent used only for the arrow and hover underline.
- Interaction: Arrow shifts and an underline draws on hover; click changes to a confirmation state.

### Trade-offs
- Strong at: Feeling native, calm, and visually light.
- Weak at: Lower discoverability than a filled button.

### Best for
- Users who prefer the notch to feel like a compact system surface rather than a web card.
