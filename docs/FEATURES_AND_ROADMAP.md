# boring.notch 機能棚卸しとロードマップ

調査日: 2026-08-10

## 今回完成した改善

- 横スクロール式の **Glances** タブを追加し、Downloads / Bluetooth / Weather / Clipboard / Focus Timer / Next Meeting の6カードを統合
- カードごとの表示・非表示と並び替え、メディアの横スワイプ曲送りと感度設定を追加
- Safari、Chromium系、Firefoxの進行中ファイルを監視し、取得済みサイズと判明する場合の進捗率を表示
- AirPods / Beatsを優先したBluetooth接続・切断ライブ表示を追加
- WeatherKitの現在天気を、現在位置または手動の緯度・経度で表示
- 初期状態OFF・ローカル限定・機密情報除外付きのClipboard Historyを追加
- 25分集中、短休憩、長休憩、カスタム時間に対応するFocus / Pomodoroタイマーを追加
- 次の予定、開始時刻、Zoom / Meet / Teams / WebexのHTTPS参加リンクを表示する会議カードを追加
- Swift strict concurrencyを全ターゲットで有効化し、Debug警告を解消
- 単体テスト4本と、Glances全カード・タブ移動・設定導線のUI回帰テスト3本を追加

## 現在利用できる機能

### Notch とウインドウ

- ノッチへのホバー、クリック、ジェスチャーによる開閉
- ホバー待ち時間、ホバー領域、ハプティック、閉じるジェスチャーと感度の調整
- ノッチ搭載・非搭載ディスプレイ別の高さ設定（実ノッチ、メニューバー、カスタム）
- 優先ディスプレイ、自動ディスプレイ切替、全ディスプレイ表示
- 前回タブの記憶、タブの常時表示、ノッチ内設定ボタン
- フルスクリーン時の表示方針、ロック画面表示、画面収録からの除外
- メニューバーアイコン、ログイン時起動、ウインドウ影、角丸スケーリング

### メディア

- Now Playing、Apple Music、Spotify、YouTube Music を再生元として選択
- アートワーク、曲名、アーティスト、経過時間、残り時間、シークバー
- 再生・一時停止、前後の曲、シャッフル、リピート、お気に入り、15秒戻る・進む、音量
- 5個の操作スロットをドラッグして並べ替え・無効化・初期化
- 再生変化時の Sneak Peek、標準・インライン表示、無操作タイムアウト
- LRCLIB からの通常歌詞・同期歌詞
- スペクトログラム、色付き表示、アルバムアート連動の色・ぼかし・発光
- 再生中アプリに応じたフルスクリーン時の非表示制御
- 閾値を調整できる横スワイプで前後の曲へ移動

### カレンダーとリマインダー

- カレンダーイベントとリマインダーの一覧表示
- 表示対象カレンダー・リストの個別選択
- 完了済みリマインダー、終日イベントの非表示
- 次の予定への自動スクロール、長いタイトルの展開
- 日付移動、イベントをカレンダーで開く、リマインダーを完了にする操作

### Shelf と共有

- ファイル、フォルダ、URL、テキスト、ドラッグデータの一時保管
- セキュリティスコープ付きブックマークによる再起動後の復元
- サムネイル、複数選択、Quick Look と Option キーでのスライドショー
- ドラッグ時のコピー、ドラッグ後の自動削除、項目がある場合の既定表示
- AirDrop を先頭にした、macOS が提供する共有サービスの自動検出
- 開く／アプリを指定して開く／Finder に表示／共有／名前変更／コピー／パスをコピー
- ファイル・フォルダの ZIP 圧縮
- 画像の背景削除、PNG・JPEG・HEIC・TIFF・BMP 変換、サイズ・品質・メタデータ設定
- 複数画像からの PDF 作成

### システム HUD

- 音量、画面輝度、キーボード輝度、マイク状態のカスタム HUD
- 開いたノッチ内・閉じたノッチ上での表示とパーセント表示
- 標準・インライン、階層色・グラデーション、アクセント色、発光の設定
- Option キー押下時にシステム設定を開く／HUD を出す／何もしない、の選択

### バッテリー

- バッテリー残量、最大容量、充電中、電源接続、低電力モードの表示
- 満充電までの時間とデスクトップモードによる充電保留の表示
- 充電・給電状態のライブ通知
- パーセントと状態アイコンの個別設定、バッテリー設定への導線

### Glances とライブ情報

- Downloads / Bluetooth / Weather / Clipboard / Focus Timer / Next Meeting の6カード
- 横スクロール、カード単位の表示切替、上下操作による並び替え
- Safari `.download`、Chromium `.crdownload`、Firefox `.part` のダウンロード監視
- AirPods / Beatsを優先した接続中Bluetooth機器と接続・切断Sneak Peek
- WeatherKitによる現在天気、現在位置・手動座標の選択
- ローカルClipboard History、保持時間・最大件数・永続化の選択、一括削除
- パスワードマネージャー、transient pasteboard、秘密鍵、一般的なAPIトークン形式の自動除外
- Focus / Pomodoro、休憩、自動休憩開始、完了セッション数、カスタム時間
- 次の会議のカウントダウンと、許可したHTTPS会議ドメインへのワンクリック参加

### カメラと外観

- ノッチ内カメラミラー、円形・矩形切替
- 待機中のフェイスアニメーション
- システムまたはカスタムのアクセント色と8色のプリセット
- スライダー色（白、アートワーク、アクセント）、プレイヤー色付け
- モダンな新アプリアイコン

### 操作・保守

- Sneak Peek とノッチ開閉のグローバルキーボードショートカット
- 初回オンボーディングと必要権限への案内
- Sparkle による更新確認と自動ダウンロード設定
- 英語以外を含むローカライズ資産

## 足場はあるが、現在は利用できない機能

- 拡張システム: 設定 UI の試作がコメントアウトされ、実行・権限モデルは未実装
- カスタム Lottie ビジュアライザー: 登録 UI と保存処理はあるが、標準スペクトログラムから切り替える設定が無効
- 代替アプリアイコン: 新しい標準アイコンは導入済みだが、実行時切替は未実装
- Clipboard Historyのグローバルショートカット: 履歴UIは完成したが、ショートカット定義との接続は未実装

## 追加・改善ロードマップ

### P0: 次に品質を固める

1. VoiceOver、キーボードだけでの操作、Reduce Motion、コントラストを含むアクセシビリティ監査を追加する。
2. ノッチ開閉、メディア操作、Shelf入出力、各権限の拒否・再許可までUIテストを広げる。
3. Developer ID署名、Notarization、SBOM、OSV/SemgrepをリリースCIに組み込む。
4. WeatherKit CapabilityとApp IDを配布用Apple Developer Teamで構成し、実機の許可・通信失敗ケースを検証する。

### P1: 完成機能を深くする

1. Bluetooth機器のバッテリー残量と、音声出力先の切替を追加する。
2. WeatherKitの時間別予報、都市検索、単位（°C / °F）を追加する。
3. Clipboard Historyの検索、ピン留め、グローバルショートカットを追加する。
4. Focus Timerを通知、メニューバー、App Intents / Shortcutsと連携する。
5. 会議カードにカレンダー選択、リマインド時刻、会議中のミュート状態を追加する。
6. Glancesをドラッグ並び替え、カード幅プリセット、表示条件ルールまで拡張する。

### P2: 差別化につながる追加機能

1. App Intents / Shortcuts。ノッチを開く、Shelfを表示、タイマー開始、表示モード変更を自動化できるようにする。
2. システムメトリクス。CPU、メモリ、ネットワーク、ストレージを選択式の軽量カードにする。
3. クイックノートとTodo。同期を必須にせず、まずローカル保存で小さく始める。
4. ストップウォッチと複数タイマー。現在のFocus Timerと共通のライブ表示基盤を使う。
5. 集中モード連携。タイマーや会議開始に合わせてmacOS Focusを切り替える。

### P3: 基盤として慎重に設計する

1. 拡張 SDK。宣言的 UI、最小権限、署名、ネットワーク許可リスト、プロセス分離、明確なアンインストールを先に設計する。
2. 通知の表示・返信。通知内容は機微情報なので、アプリ除外、ロック画面非表示、画面共有時の自動抑制を必須にする。
3. ロックスクリーンウィジェット。現行のロック画面表示と責務が重ならないよう、表示情報を限定する。

## 優先順位の根拠

競合では、MediaMate が HUD と Now Playing、NotchNook がウィジェット・ライブアクション・Shelf、Alcove が通知・ライブアクティビティ・ロック画面、SuperIsland が天気・会議参加・拡張 SDK を提供している。App Store の近年の競合では、Clipboard、Weather、Timer、Quick Notes、System Metrics が標準的になりつつある。

boring.notch は Media、Calendar、Shelf、HUD、Battery、Mirrorに加えて6つのGlancesカードが揃った。次は機能数だけを増やすより、P0の配布品質・アクセシビリティと、P1の既存カードの深掘りが最も費用対効果が高い。
